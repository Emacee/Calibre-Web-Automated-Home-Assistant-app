# Shelfmark

Home Assistant app for [Shelfmark](https://github.com/calibrain/shelfmark):
search books, also from your Hardcover lists such as Want to Read (which
it can also download automatically), and download them straight into the ingest folder of the Calibre-Web Automated
app, in the Home Assistant sidebar via Ingress.

See [DOCS.md](DOCS.md) for setup and configuration.
