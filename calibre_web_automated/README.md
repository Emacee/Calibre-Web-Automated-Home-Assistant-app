# Calibre-Web Automated

Home Assistant app for [Calibre-Web Automated](https://github.com/crocodilestick/Calibre-Web-Automated):
an e-book library with a web reader, automatic import and conversion of new
books, OPDS and Kobo sync — in the Home Assistant sidebar via Ingress.

See [DOCS.md](DOCS.md) for setup and configuration.
